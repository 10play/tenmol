### cmd.dump

The dump command writes the geometry of an isosurface, isomesh, isodot, or map object to a simple text file. Each line contains one vertex in case of representations, or one grid point in case of a map. For surface objects, XYZ coordinates and the normal are exported. Three lines make one triangle (like GL_TRIANGLES). For mesh objects, XYZ coordinates are exported (no normals). The vertices form line strips (like GL_LINE_STRIP), a blank line starts a new strip.
