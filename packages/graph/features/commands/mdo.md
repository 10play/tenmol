## Purpose
`mdo` binds generalized command-line operations to a numbered movie frame; those commands execute every time the frame is played. It is the building block behind movie utilities like `movie.rock`. Unlike `mappend`, it *replaces* whatever was on the frame.

## Syntax
`mdo(frame, command)`

| Param | Type | Default | Meaning |
| --- | --- | --- | --- |
| `frame` | int | — | The 1-based frame to define |
| `command` | str | — | Command-line text; may contain several `;`-separated commands |

## Behaviour
Calls `_cmd.mdo(frame-1, command, 0)` — flag `0` overwrites the frame's existing command (vs `mappend`, which passes `1` to append). The movie must be defined with `mset` first, or `mdo` has no effect; redefining the movie clears all `mdo`/`mappend` commands. These are usually generated by PyMOL utilities rather than typed by hand.

## Examples
```python
load test.pdb
mset 1
mdo 1, turn x, 5; turn y, 5;
mplay
```
